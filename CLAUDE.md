# Exchange Rates Routine

Small routine that tracks USD exchange rates for EUR, GBP and BRL.

## How it works
- `update_rates.py` (Python 3, standard library only) fetches the latest rates from
  `https://api.frankfurter.dev/v1/latest?base=USD&symbols=EUR,GBP,BRL`.
- Rates are upserted into `data/rates.csv` (columns: `date, currency, rate, updated_at`),
  keyed on `(date, currency)`: existing rows are updated, new ones inserted.
- `data/summary.md` is fully rewritten each run with the latest rate per currency
  and the run time in UTC.
- The script prints how many rows were inserted and updated.

## Run
```
python update_rates.py
```

## Conventions
- Keep it dependency-free (standard library only).
- `updated_at` and the summary run time are UTC (`YYYY-MM-DD HH:MM:SS`).
- Don't edit files in `data/` by hand; they are generated by the script.
